## Como utilizar?
Para poder utilizar o nosso código, siga as seguintes instruções:
```
git clone https://github.com/Gabrields1998/GraficosEnade.git
```
Acesse a pasta e execute o arquivo `main.py`:

 - No Linux, pressione o botão `F4` para abrir o terminal, e, nele, insira os seguintes comandos:
	```
	python3 -m pip install -r requirements.txt
	
	python3 main.py
	```
